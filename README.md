# PPL Chikumi Bangkalan

Proyek Pengembangan Perangkat Lunak (PPL) untuk UMKM Chikumi Bangkalan.

## Deskripsi Proyek

Pengembangan aplikasi penjualan dan manajemen stok yang mencakup katalog produk, keranjang belanja, checkout, pengelolaan pesanan, dashboard penjualan, dan prediksi kebutuhan stok menggunakan metode Moving Average.
